# 围棋·静心对弈

这是一个可直接导入微信开发者工具的**原生微信小游戏**项目。项目以 Canvas 绘制 19 路棋盘与棋子，提供本地双人轮流对弈体验；不依赖网络服务或第三方运行时。

## 已实现功能

| 模块 | 实现内容 |
|---|---|
| 对弈界面 | 木纹风格 19 路棋盘、星位、黑白棋子、最后一手标记、回合与提子数显示。 |
| 交互控制 | 点击交叉点落子；提供新局、悔棋、虚手与认输按钮。 |
| 核心规则 | 空点校验、提子、禁入点校验、全局同形禁着、双方连续虚手结束。 |
| 终局展示 | 双方连续虚手或认输后展示结果；自动计算简易领地、提子与 6.5 目贴目。 |
| 工程质量 | 规则引擎单元测试、画布渲染与触控命中冒烟测试。 |

> 当前采用适合快速对局的**简易自动数目**：只计算被单一颜色包围的空点和提子数。严谨比赛场景中的死活确认与争议处理，仍需由对弈双方在终局前手动确认。

## 导入与运行

在微信开发者工具中选择“导入项目”，并将项目目录指向本目录 `wechat-go`。首次导入时可使用测试 AppID；准备发布时，请将 `project.config.json` 内的 `appid` 替换为自己的小游戏 AppID。选择“小游戏”项目类型后，编译即可在模拟器或真机中运行。

| 文件或目录 | 说明 |
|---|---|
| `game.js` | 小游戏入口，绑定触摸事件与前后台生命周期。 |
| `game.json` | 横竖屏与状态栏等小游戏运行配置。 |
| `project.config.json` | 微信开发者工具项目配置。 |
| `js/core/GoEngine.js` | 无界面依赖的围棋规则引擎。 |
| `js/render/CanvasRenderer.js` | 原生 Canvas 棋盘和控件渲染器。 |
| `js/GameController.js` | 触摸事件、规则引擎、界面的协调层。 |
| `tests/` | 可在 Node.js 中运行的规则与渲染测试。 |

## 操作说明

黑方先行。点击棋盘交叉点即可落子；成功落子后会自动切换回合。若落子点已有棋子、形成无气的禁入点或使棋盘局面重复，游戏会提示并拒绝该手棋。点击“虚手”可放弃本手，双方连续虚手后自动数目并显示胜负。点击“悔棋”会撤回最近一步，包括虚手；点击“认输”则直接结束当前对局。

## 本地测试

如果本机安装了 Node.js，可在此目录执行以下命令以验证不依赖微信运行时的逻辑代码：

```bash
node tests/GoEngine.test.js
node tests/CanvasRenderer.test.js
```

测试覆盖提子、禁入点、悔棋、连续虚手、占点校验，以及画布渲染与控件触控命中。

## 后续可扩展方向

项目结构已将规则和渲染解耦，后续可以在不重写棋盘规则的情况下加入人机对战、落子音效、对局记录（SGF）、房间联机、不同棋盘规格和更严谨的终局死活确认流程。
